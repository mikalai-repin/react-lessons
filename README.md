# React

[WEB](https://react-livecode.netlify.app/)

Интерактивный курс по React 19 и его экосистеме на русском языке: текст урока, редактор кода и живое приложение в одном окне. В ходе курса вы с нуля пишете интернет-магазин настольных игр «Ход конём» — от первой карточки до каталога с сервера, корзины, оформления заказа, входа и админки на Ant Design, — а затем разбираетесь, как React устроен изнутри, и переносите приложение в Vite-проект и на Next.js.

Для кого: разработчики, которые знают JavaScript/TypeScript и веб, но не писали на React (или хотят разобраться в нём глубоко, до уровня senior).

Что входит, кроме React: React Router, TanStack Query, Zustand, Redux Toolkit, React Hook Form + Zod, Ant Design, Vitest + Testing Library, React Compiler, Next.js (обзор серверного React) — см. [docs/libraries.md](docs/libraries.md).
