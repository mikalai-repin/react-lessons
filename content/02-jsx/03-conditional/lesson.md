Не все игры одинаковые: у одних есть скидка, и рядом с ценой нужна зачёркнутая старая; другие распроданы, и вместо кнопки «В корзину» нужна надпись «Нет в наличии». Разметка зависит от данных — это **условный рендер**.

В JSX нет специальных конструкций для условий (как `@if` в Angular или `v-if` во Vue). Условия — обычный JavaScript, и их три вида.

## Ранний return

Компонент — функция, а функция может вернуть разное в зависимости от условия. Возьмём игру не по позиции в массиве, а по id — как будет на странице игры, когда появится роутинг:

```tsx
const game = games.find((g) => g.id === FEATURED_ID);
if (!game) {
  return <p className={styles.page}>Игра не найдена</p>;
}
```

`find` возвращает `Game | undefined`: игры с таким id может не быть. Если её нет — компонент сразу возвращает сообщение, и до основной разметки дело не доходит. Ранний `return` хорош, когда условие меняет **всё**, что показывает компонент: «загружается», «ошибка», «не найдено».

Заодно TypeScript **сужает тип**: после проверки он знает, что ниже `game` — точно `Game`. Без проверки каждое `game.title` было бы ошибкой `'game' is possibly 'undefined'.`

## && — показать или ничего

Старую цену нужно показать, только если она есть:

```tsx
{game.oldPrice !== undefined && (
  <s className={`muted ${styles.oldPrice}`}>
    {formatPrice(game.oldPrice)}
  </s>
)}
```

Оператор `&&` возвращает левую часть, если она ложная, и правую — если истинная. Если условие ложно, в разметку попадёт `false`, а `false`, как вы видели в первом шаге, не рисуется. Если истинно — React-элемент `<s>`.

Два класса на одном элементе — это одна строка с классами через пробел, поэтому здесь шаблонная строка: глобальный `muted` и `styles.oldPrice` из модуля.

## Тернарный оператор — одно или другое

Когда при ложном условии нужно показать что-то другое, подходит `? :`:

```tsx
{soldOut ? (
  <p className={styles.soldOut}>Нет в наличии</p>
) : (
  <button className="button">В корзину</button>
)}
```

Условие `soldOut` вычислено заранее, до `return`: `const soldOut = game.inStock === 0;`. Длинные условия удобнее читать по имени, чем разбирать внутри разметки. Кнопка пока ничего не делает — обработчики событий появятся в главе 4.

```tsx App.tsx {6,9-13,34-38,41-45}
import { games } from './data/games';
import { formatPrice } from './shared/format';
import styles from './App.module.css';

const MAX_RATING = 5;
const FEATURED_ID = 1;

export function App() {
  const game = games.find((g) => g.id === FEATURED_ID);
  if (!game) {
    return <p className={styles.page}>Игра не найдена</p>;
  }
  const soldOut = game.inStock === 0;

  return (
    <main className={styles.page}>
      <h1 className={styles.title}>♞ Ход конём</h1>
      <p className="muted">
        Магазин настольных игр · в каталоге {games.length} игр
      </p>

      <article
        className={styles.card}
        data-category={game.category}
      >
        <img
          className={styles.cover}
          src={game.cover}
          alt={game.title}
        />
        <h2 className={styles.cardTitle}>{game.title}</h2>
        <p className={styles.price}>
          {formatPrice(game.price)}
          {game.oldPrice !== undefined && (
            <s className={`muted ${styles.oldPrice}`}>
              {formatPrice(game.oldPrice)}
            </s>
          )}
        </p>
        {/* … игроки и рейтинг без изменений … */}
        {soldOut ? (
          <p className={styles.soldOut}>Нет в наличии</p>
        ) : (
          <button className="button">В корзину</button>
        )}
      </article>
    </main>
  );
}
```

::: task
1. Объявите константу `FEATURED_ID = 1` и найдите игру через `games.find`. Если игры нет, верните `<p className={styles.page}>Игра не найдена</p>`.
2. Объявите `soldOut` — распродана ли игра (`inStock === 0`).
3. После цены покажите старую цену в `<s>` с классами `muted` и `styles.oldPrice`, только если она есть.
4. В конце карточки — «Нет в наличии» (класс `styles.soldOut`) для распроданной игры или кнопку `<button className="button">В корзину</button>`.
:::

## Что получилось

У «Острова сокровищ» рядом с ценой зачёркнутая старая — «2 490 ₽», внизу красная кнопка «В корзину». Поменяйте `FEATURED_ID`:

- `7` — «Маяк»: старой цены нет, вместо кнопки — «Нет в наличии»;
- `99` — такой игры нет: на экране только «Игра не найдена».

Верните `1`.

## Ловушка: && с числом

Хочется показать остаток на складе: «На складе: 12 шт.». Самый короткий способ — проверить число прямо в `&&`. Поставьте `FEATURED_ID = 7` и добавьте перед блоком с кнопкой:

```tsx
{game.inStock && <p>На складе: {game.inStock} шт.</p>}
```

У «Маяка» на складе ноль, надписи быть не должно. Но в карточке появился одинокий **`0`** над «Нет в наличии». Почему? `0 && …` возвращает левую часть — `0`. А `0`, в отличие от `false`, React рисует (помните таблицу из первого шага).

TypeScript здесь не поможет: `0` — допустимый `ReactNode`, ошибки нет. Правило: **слева от `&&` в JSX — только настоящее логическое значение**: `game.inStock > 0 && …`, `items.length > 0 && …`, `!!count && …`. Поэтому и старую цену мы проверяли через `!== undefined`, а не просто `game.oldPrice && …`: цена `0` нарисовала бы `0`.

Исправьте условие на `game.inStock > 0` и убедитесь, что ноль пропал. Затем удалите строку и верните `FEATURED_ID = 1`.

::: tip Как в настоящем проекте
Склеивать классы шаблонной строкой неудобно, когда их несколько и они условные. В проектах для этого берут крошечную библиотеку [clsx](https://github.com/lukeed/clsx): `clsx('muted', styles.oldPrice, soldOut && styles.dim)` — ложные значения она пропускает. В курсе классов немного, обходимся строками.
:::

::: tip
Ещё один частый приём — `null` в тернарном операторе: `{soldOut ? null : <button>…</button>}`. Работает, но `!soldOut && <button>…</button>` короче. Тернарный оператор оставляйте для «одно или другое».
:::
