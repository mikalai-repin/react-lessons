Пора собрать всё вместе. Магазин снова на месте: демо из прошлого шага убрано, `main.tsx` опять рисует `App`. Карточке не хватает того, что в настоящих магазинах бросается в глаза первым, — бейджей поверх обложки и тегов.

Обложка уже обёрнута в `<div className={styles.media}>`: бейджи будут лежать поверх неё, в углу. Стили бейджей (`styles.badges`, `styles.badge`) и тегов (`styles.tags`) готовы в `App.module.css`. Места для вашего кода отмечены комментариями `TODO` в `App.tsx`.

::: task
1. Объявите над компонентом константы порогов: `HIT_RATING` — рейтинг, с которого игра считается хитом (4.6), и `FEW_LEFT` — сколько штук на складе считается «мало» (5).
2. В теле функции в `map` вычислите `discount` — скидку в процентах, округлённую до целого: у «Острова сокровищ» (1 990 вместо 2 490) это 20. Если старой цены нет — 0.
3. Поверх обложки, в `<div className={styles.badges}>`, покажите бейджи `<span className={styles.badge}>`:
   - «−20%» — если скидка есть;
   - «Хит» — если рейтинг не ниже `HIT_RATING`;
   - «Осталось 3 шт.» — если игра есть на складе, но не больше `FEW_LEFT` штук.
4. После характеристик выведите теги игры списком `<ul className={styles.tags}>`: каждый тег — `<li>` с решёткой, «#пираты».
:::

::: hint Подсказка 1: с чего начать
Идите по комментариям `TODO` сверху вниз. Константы и `discount` — обычный TypeScript до `return`. Бейджи — три независимых условия, поэтому три `&&`, а не тернарный оператор: у одной игры может быть сразу несколько бейджей.
:::

::: hint Подсказка 2: как посчитать скидку
Доля цены от старой — `game.price / game.oldPrice`, скидка — `1 - доля`, в процентах — умножить на 100 и `Math.round`. Но `oldPrice` необязательное поле, и TypeScript не даст делить на возможный `undefined`. Проверьте его тернарным оператором: `game.oldPrice === undefined ? 0 : …`.
:::

::: hint Подсказка 3: откуда на обложках «0»
Если на карточках без скидки в углу появился одинокий `0`, вы написали `{discount && …}`. Это ловушка из шага про условный рендер: `0 && …` возвращает `0`, а ноль React рисует. Слева от `&&` должно быть логическое значение: `discount > 0 && …`.
:::

::: hint Подсказка 4: список тегов
Теги — массив строк, значит `game.tags.map((tag) => <li …>#{tag}</li>)`. Не забудьте `key`: id у тега нет, но сами строки внутри одной игры уникальны — тег и есть ключ.
:::

## Проверьте себя

- «Остров сокровищ»: бейджи «−20%» и «Хит», теги «#пираты #карты».
- «Ночной экспресс»: «−11%», «Хит» и «Осталось 3 шт.» — бейджи переносятся на вторую строку.
- «Маяк»: бейджей нет. Рейтинг 4.5 — ниже порога, а «Осталось…» не показывается, потому что на складе ноль.
- «Драконья почта» и «Космические коты»: ни бейджей, ни нулей в углу обложки.
- Консоль пуста: нет предупреждений про `key`.

## Итоги главы

Вы нарисовали каталог из данных и разобрали JSX целиком:

| Запись | Что делает |
|---|---|
| `{выражение}` | значение из JavaScript в тексте или атрибуте; инструкции (`if`, `for`) — до `return` |
| `attr="строка"`, `attr={выражение}` | строка как есть или выражение; имена — как у свойств DOM: `className`, `htmlFor`, `tabIndex` |
| `style={{ width: 50 }}` | объект стилей, camelCase, числа — пиксели |
| `data-*`, `aria-*` | пишутся как в HTML |
| `cond && <X />`, `cond ? <X /> : <Y />`, ранний `return` | условный рендер |
| `items.map((item) => <X key={item.id} />)` | список; `key` — устойчивый id из данных |
| `<>…</>`, `<Fragment key>` | группа элементов без обёртки в DOM |
| `dangerouslySetInnerHTML={{ __html }}` | HTML-строка как есть, без очистки |

И несколько важных идей:

- `null`, `undefined`, `true` и `false` не рисуются, а `0` и `NaN` — рисуются. Слева от `&&` — только логическое значение;
- всё, что выводится через `{}`, экранируется — защита от XSS по умолчанию. `dangerouslySetInnerHTML` HTML не чистит, а `javascript:`-адреса React 19 блокирует только в своих атрибутах;
- по `key` React сопоставляет элементы списка между рендерами: тот же ключ — тот же элемент вместе с DOM-состоянием. Индекс как ключ путает состояние строк, когда список меняется.

Карточка заняла семьдесят строк из ста с лишним и вложена в шесть уровней разметки — читать `App` всё труднее. В следующей главе вынесем её в собственный компонент `GameCard`, научимся передавать в него данные через **props** и соберём карточку из ещё более мелких частей.
