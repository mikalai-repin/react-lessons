В каждом новом проекте на React компонент `App` в `main.tsx` обёрнут в `<StrictMode>`. Это не украшение: строгий режим заставляет React вести себя «неудобно» во время разработки, чтобы ошибки находились сразу, а не в продакшене.

## Что делает строгий режим

**Строгий режим** (`StrictMode`) — компонент из пакета `react`. Он ничего не рисует сам, а включает дополнительные проверки для всех компонентов внутри:

- **вызывает каждый компонент дважды** при отрисовке. Компонент должен быть **чистым**: при тех же входных данных возвращать ту же разметку и ничего не менять снаружи — не писать в глобальные переменные, не отправлять запросы. Если компонент что-то меняет снаружи, двойной вызов это покажет;
- **дважды запускает эффекты** — код, который компонент выполняет после отрисовки. До эффектов мы дойдём в главе 6, и там двойной запуск окажется очень полезным;
- **предупреждает об устаревших возможностях** React.

Всё это — только в режиме разработки. В продакшен-сборке `StrictMode` не делает ничего, и компоненты вызываются один раз.

```tsx main.tsx {1,11-15}
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { App } from './App';

// Элемент, внутри которого React рисует приложение
const container = document.getElementById('root');
if (!container) throw new Error('На странице нет элемента #root');

const root = createRoot(container);
root.render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

`<StrictMode>` здесь — открывающий и закрывающий тег, а `<App />` — внутри него. Так в JSX вкладывают одно в другое: компонент `StrictMode` получает `App` как содержимое и рисует его, добавляя проверки.

::: task
Импортируйте `StrictMode` из `react` и оберните им `<App />` в `main.tsx`.
:::

## Что получилось

На экране всё по-прежнему. Чтобы увидеть двойной вызов, добавьте в начало функции `App` строку:

```tsx App.tsx {2}
export function App() {
  console.log('render App');
  return (
```

В консоли превью появится `render App` со счётчиком **2**: консоль сворачивает одинаковые строки подряд в одну. React вызвал функцию дважды. Теперь уберите `<StrictMode>` из `main.tsx` — счётчика нет, вызов один. Верните `StrictMode` и уберите `console.log`.

::: warning
Не пытайтесь «починить» двойной вызов. Если из-за него что-то сломалось — например, счётчик вызовов растёт на 2, — значит, компонент не чистый, и в продакшене та же ошибка проявится иначе и позже. Во всём курсе приложение работает в строгом режиме, как в новом проекте Vite.
:::

::: tip
Отрисовку компонента в React называют **рендером** (render): React вызывает функцию компонента и получает от неё разметку. Рендер — это ещё не изменение страницы: что поменять в DOM, React решает после. Это различие понадобится уже в главе 4.
:::
