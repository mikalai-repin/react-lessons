## Что такое React

**React** — библиотека для построения пользовательских интерфейсов. Её сделали в Facebook и открыли в 2013 году, сейчас её развивают Meta и сообщество. Главное слово здесь — **библиотека**.

React отвечает за одну задачу: по данным приложения нарисовать интерфейс и поддерживать его в актуальном состоянии, когда данные меняются. Всё остальное — переходы между страницами, запросы к серверу, формы, хранение состояния — React не делает. Для этого есть библиотеки экосистемы, и выбирает их команда проекта.

Если вы знакомы с Angular, разница видна сразу:

| Задача | Angular | React |
|---|---|---|
| Компоненты и разметка | `@angular/core` | React |
| Переходы между страницами | `@angular/router` | библиотека: React Router, TanStack Router… |
| Запросы к серверу и кэш | `@angular/common/http` | библиотека: TanStack Query, RTK Query, SWR… |
| Формы и проверка ввода | `@angular/forms` | библиотека: React Hook Form + Zod… |
| Общее состояние приложения | сервисы и DI | контекст React или библиотека: Zustand, Redux Toolkit… |
| Готовые компоненты интерфейса | Angular Material | библиотека: Ant Design, MUI… |

Плата за свободу — каждый проект на React собран из своего набора библиотек, и их нужно знать. Поэтому в курсе мы изучаем не только React, но и самые распространённые библиотеки вокруг него: React Router, TanStack Query, Zustand, Redux Toolkit, React Hook Form, Zod и Ant Design. Каждая появится тогда, когда вы сделаете то же самое руками и увидите, чего не хватает.

## Компоненты и JSX

Интерфейс в React собирается из **компонентов**. Компонент — это обычная функция, которая возвращает описание разметки. Вот карточка игры из магазина, слегка сокращённая:

```tsx shared/GameCard.tsx
export function GameCard({ game, onAdd }: GameCardProps) {
  return (
    <article className={styles.card}>
      <div className={styles.title}>{game.title}</div>
      <button className="button" onClick={() => onAdd(game)}>
        В корзину
      </button>
    </article>
  );
}
```

Разметка внутри функции похожа на HTML, но это **JSX** — расширение синтаксиса JavaScript. В фигурных скобках — обычные выражения JavaScript: `{game.title}` подставляет название игры, а `onClick` получает функцию. Браузер JSX не понимает: перед запуском каждый тег превращается в вызов функции. Это делает компилятор TypeScript — в превью курса прямо в браузере, а в настоящем проекте при сборке. Что именно получается из JSX, вы увидите в последнем шаге главы.

Обратите внимание: в React нет отдельного языка шаблонов. Условия и списки — это обычный JavaScript (`&&`, `map`) внутри JSX. Поэтому TypeScript проверяет разметку так же, как остальной код.

## React сегодня

Курс написан для **React 19**. За двенадцать лет React сильно изменился, и в интернете много кода для старых версий.

::: warning
Если вы видите классы (`class Cart extends React.Component`), `componentDidMount`, `this.setState`, `ReactDOM.render` или `forwardRef` — это прошлое React. Такой код встречается в существующих проектах, поэтому в курсе мы покажем его во врезках «Вы встретите в старом коде». Но писать мы будем по-современному: функции-компоненты и хуки.
:::

Библиотеки экосистемы тоже меняются быстро. Курс использует их актуальные версии: React Router 8, TanStack Query 5, Ant Design 6.

## Как устроена страница курса

- **Слева** — текст шага. Внизу кнопки «Назад», «Далее» и «Решение»: решение подставляется в редактор, а ваш код сохраняется, и его можно вернуть.
- **В центре** — редактор. Вкладки — файлы шага. Кнопка «☰ Файлы» показывает их деревом, как в настоящем проекте. Редактор знает типы React и библиотек: наведите курсор на `useQuery` в `catalog/Catalog.tsx` — появится подсказка.
- **Справа** — работающее приложение. Над ним адресная строка, под ним консоль и вкладка «Сеть»: в ней видны запросы, которые магазин отправляет учебному серверу.

Код запускается сам через секунду после правки (переключатель «Автозапуск») или по `Ctrl/Cmd + Enter`. Всё, что вы пишете, сохраняется в браузере.

::: task
Освойтесь в интерфейсе:

1. Откройте любую игру и добавьте её в корзину. Посмотрите, как изменился адрес в строке над приложением.
2. Наберите в адресной строке `/cart` и нажмите Enter.
3. Откройте вкладку «Сеть» под приложением и наберите что-нибудь в поиске каталога. Каждый запрос виден в списке; щёлкните по строке, чтобы увидеть ответ сервера.
4. Откройте дерево файлов кнопкой «☰ Файлы».
:::

Во вкладке «Сеть» самый первый запрос каталога отмечен как «отменён», а сразу за ним идёт такой же успешный. Это не ошибка: в режиме разработки React специально монтирует каждый компонент дважды, чтобы помочь найти ошибки, и первый запрос становится не нужен. Зачем так сделано, разберём в шаге про строгий режим.

Если поставить во вкладке «Сеть» задержку 3000 мс и начать быстро печатать в поиске, часть запросов тоже окажется отменённой: ответ на них уже не нужен. Как это работает, разберём в главе про данные с сервера.
