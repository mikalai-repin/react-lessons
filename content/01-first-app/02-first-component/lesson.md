## Компонент — функция, которая возвращает разметку

Интерфейс приложения на React собирается из **компонентов**. Компонент — это кусок страницы со своей разметкой и поведением: шапка магазина, карточка игры, корзина. Компоненты вкладываются друг в друга, и вся страница — это дерево компонентов с одним корнем.

Технически компонент — обычная функция JavaScript, которая возвращает описание того, что нужно нарисовать:

```tsx App.tsx {2-7}
export function App() {
  return (
    <main>
      <h1>Ход конём</h1>
      <p>Магазин настольных игр</p>
    </main>
  );
}
```

Разметка внутри `return` — это **JSX**: синтаксис, похожий на HTML, прямо в коде. Круглые скобки вокруг нужны только для того, чтобы разметку можно было начать с новой строки: без них JavaScript закончил бы `return` на первой строке.

Три правила, которые действуют с первого же компонента:

- **Имя компонента — с большой буквы.** `App`, `GameCard`, `CartPage`. По первой букве React отличает свои компоненты от тегов HTML: `<main>` — тег, `<App />` — компонент.
- **Компонент возвращает один корневой элемент.** Заголовок и абзац мы обернули в `<main>`. Два соседних элемента без обёртки вернуть нельзя — почему, станет ясно в последнем шаге главы.
- **Компонент экспортируется**, чтобы его могли использовать другие файлы: `export function App`. В `main.tsx` он импортируется так: `import { App } from './App'`.

## Как компонент попадает на страницу

Загляните в `main.tsx`:

```tsx main.tsx
import { createRoot } from 'react-dom/client';
import { App } from './App';

createRoot(document.getElementById('root')!).render(<App />);
```

`<App />` — так в JSX используют компонент: как тег с его именем. Подробно этот файл разберём в следующем шаге, а пока достаточно: он находит на странице элемент `#root` и просит React нарисовать внутри него `App`.

::: task
Пусть `App` вернёт разметку магазина вместо `null`: элемент `<main>`, внутри него заголовок `<h1>` «Ход конём» и абзац `<p>` «Магазин настольных игр».
:::

## Что получилось

В превью появились заголовок и абзац. Превью перезапускается само через секунду после каждой правки — поменяйте текст в заголовке и посмотрите.

Поэкспериментируйте:

- **Уберите обёртку `<main>`**, оставив заголовок и абзац рядом. Код перестанет собираться: в консоли ошибка с меткой «Сборка» — `App.tsx:3 — JSX expressions must have one parent element.` («у выражения JSX должен быть один родительский элемент»), а вместо приложения — сообщение, что оно не запущено. Верните `<main>`.
- **Назовите компонент с маленькой буквы**: `export function app()` в `App.tsx`, а в `main.tsx` — `import { app } from './App'` и `<app />`. Редактор подчеркнёт `<app />`: `Property 'app' does not exist on type 'JSX.IntrinsicElements'` — TypeScript считает это тегом HTML, а такого тега нет. Код при этом запустится (ошибки типов запуск не останавливают), но превью будет пустым, а в консоли React предупредит: `The tag <app> is unrecognized in this browser. If you meant to render a React component, start its name with an uppercase letter.` React создал на странице пустой элемент `<app>` вместо того, чтобы вызвать вашу функцию. Верните большую букву.

::: tip
Если вы пришли из Angular: здесь нет декоратора, селектора и шаблона в отдельной строке. Компонент — просто функция, а место на странице для него задаёт не селектор, а то, где написан `<App />`.
:::

::: legacy Вы встретите в старом коде: классовые компоненты
До 2019 года компоненты с состоянием писали классами:

```tsx
class App extends React.Component {
  render() {
    return <h1>Ход конём</h1>;
  }
}
```

Такой код по-прежнему работает, и в старых проектах его много. Но новые возможности React доступны только функциям, поэтому в курсе все компоненты — функции. Ещё одна примета старого кода — `import React from 'react'` в начале каждого файла: до React 17 без неё не работал JSX.
:::
