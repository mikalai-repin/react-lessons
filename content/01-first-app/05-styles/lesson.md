Магазин пока выглядит как документ из 90-х. В шаге появились два готовых файла со стилями: `styles.css` — общие стили всего магазина, и `App.module.css` — стили компонента `App`. Писать CSS не придётся (курс про React, а не про вёрстку), но подключить стили нужно самим — и тут у React есть свои правила.

## Глобальные стили

`styles.css` — **глобальные стили**: цвета магазина в переменных (`--brand`), шрифты, кнопки, служебные классы вроде `.muted` для приглушённого текста. Они действуют на всю страницу.

Подключаются они импортом в `main.tsx`:

```tsx main.tsx {3}
import { createRoot } from 'react-dom/client';
import { App } from './App';
import './styles.css';
```

Импорт CSS-файла — не возможность JavaScript, а соглашение сборщика: Vite видит такой импорт и добавляет стили на страницу. Превью курса делает то же самое. Импорт без имени (`import './styles.css'`) означает «просто подключи».

## Классы в JSX: className

Класс элементу в JSX задаётся атрибутом **`className`**, а не `class`:

```tsx
<p className="muted">Магазин настольных игр</p>
```

JSX превращается в JavaScript, а в JavaScript `class` — ключевое слово. Поэтому React использует название свойства DOM: у элемента в браузере тоже `element.className`, а не `element.class`.

## Стили компонента: CSS Modules

Глобальные стили удобны для общих вещей, но опасны для компонентов: класс `.title` из стилей шапки заденет все `.title` на странице. Поэтому стили отдельного компонента пишут в **CSS Modules** — файлах с окончанием `.module.css`:

```css App.module.css
.page {
  padding: 16px;
}

.title {
  color: var(--brand);
}
```

Такой файл импортируется с именем — и получается объект, где ключи — имена классов:

```tsx App.tsx {1,5-6}
import styles from './App.module.css';

export function App() {
  return (
    <main className={styles.page}>
      <h1 className={styles.title}>♞ Ход конём</h1>
      <p className="muted">Магазин настольных игр</p>
    </main>
  );
}
```

Фигурные скобки в `className={styles.page}` означают «здесь выражение JavaScript, а не строка». Подробнее о выражениях в JSX — в главе 2.

::: task
1. Подключите глобальные стили: `import './styles.css'` в `main.tsx`.
2. В `App.tsx` импортируйте `styles` из `./App.module.css`, дайте `<main>` класс `styles.page`, заголовку — `styles.title`, а абзацу — глобальный класс `muted` (строкой). Добавьте в заголовок коня: `♞ Ход конём`.
:::

## Что получилось

Заголовок стал меньше и фирменного красного цвета (размер — из глобальных стилей, цвет — из `App.module.css`), у страницы появился отступ, а подпись стала серой.

Посмотрите, какой класс получил заголовок на самом деле: добавьте в конец `main.tsx` строку `setTimeout(() => console.log(document.querySelector('h1')?.className), 100);`. В консоли будет не `title`, а что-то вроде `App_title_x7k2p`. Сборка переименовала класс так, чтобы он был уникальным во всём приложении, а объект `styles` хранит соответствие «`title` → новое имя». Поэтому `.title` в другом компоненте с этим не пересечётся. Уберите строку.

Ещё эксперимент: напишите `className={styles.titel}` с опечаткой. Ошибки не будет ни в консоли, ни в редакторе — `styles.titel` просто `undefined`, и класс не применится. Это обратная сторона CSS Modules: имена классов не проверяются. Верните `title`.

::: tip Как в настоящем проекте
Vite поддерживает CSS Modules без настройки, но придумывает имена классов по-своему — точный вид имени в превью и в проекте отличается. Важно другое: имя уникально и связано с файлом модуля.
:::

::: deep Другие способы стилизации
Кроме глобального CSS и CSS Modules, в проектах на React встречаются Tailwind (готовые классы-утилиты прямо в разметке: `className="p-4 text-red-700"`), CSS-in-JS (стили в JavaScript: styled-components, Emotion) и готовые наборы компонентов со своими стилями, например Ant Design. Сравним их в главе 15, а до неё используем CSS Modules — их поддерживает любой проект на Vite.
:::
