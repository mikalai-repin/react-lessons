Последняя деталь карточки, которая ещё не стала компонентом, — полоска рейтинга. По тонкой жёлтой линии трудно понять, 4,3 у игры или 4,8. В магазинах рейтинг показывают звёздами, и понадобится он не только в карточке: на странице игры, в отзывах, в фильтре каталога. Соберите компонент `Rating`.

Стили готовы в `shared/Rating.module.css`, в `shared/Rating.tsx` — только комментарий `TODO`.

::: task
1. В `shared/Rating.tsx` объявите тип `RatingProps`: `value` — рейтинг (число), необязательные `max` — сколько всего звёзд и `size` — `'sm'` или `'md'`.
2. Объявите и экспортируйте `Rating`. По умолчанию `max` — 5, `size` — `'md'`.
3. Нарисуйте `max` звёзд — символ `★` в `<span>`. Закрашены первые `Math.round(value)` (класс `styles.on`), остальные — пустые (`styles.off`). После звёзд — само число в `<span className={styles.value}>`.
4. Оберните всё в `<span>` с классами `styles.rating` и `styles[size]`. Для программ экранного доступа это одна картинка: `role="img"` и `aria-label` «Рейтинг 4.6 из 5».
5. В `GameCard.tsx` замените полоску на `<Rating value={game.rating} size="sm" />`. Константа `MAX_RATING` и классы `rating`, `ratingFill` в `GameCard.module.css` больше не нужны — удалите их.
:::

::: hint Подсказка 1: с чего начать
`Rating` устроен как `Badge` из шага про `children`: тип props рядом, значения по умолчанию в деструктуризации, класс размера — `styles[size]`, как класс тона у бейджа. Новое здесь только одно — нарисовать несколько звёзд.
:::

::: hint Подсказка 2: как нарисовать N звёзд
Нужен массив длиной `max`, который можно перебрать `map`. Удобно сразу положить в него, закрашена ли звезда: `Array.from({ length: max }, (_, i) => i < filled)` даёт `[true, true, true, true, false]` при `filled = 4`. Дальше — `stars.map((on, i) => <span …>★</span>)`, класс — `on ? styles.on : styles.off`.
:::

::: hint Подсказка 3: что взять ключом
У звезды нет id. Здесь ключ-индекс — тот самый безопасный случай из шага про `key` в главе 2: звёзды никогда не переставляются, не фильтруются и не хранят состояния — позиция и есть идентичность. `key={i}`.
:::

::: hint Подсказка 4: зачем role="img"
Без `role` и `aria-label` программа экранного доступа прочитает пять звёздочек и число подряд. С `role="img"` весь рейтинг становится одной картинкой с понятным описанием — так же была устроена полоска рейтинга в главе 2.
:::

## Итоги главы

Магазин стал деревом компонентов: `App` → `Header`, `Section` → `GameCard` → `Badge`, `Rating`, `Button`. Каждый — в своём файле со своими стилями.

| Запись | Что делает |
|---|---|
| `export function GameCard(…) { return … }` | компонент — функция с большой буквы, которая возвращает JSX |
| `<GameCard game={game} />` | элемент компонента; атрибуты собираются в объект props |
| `type GameCardProps = { game: Game }` | тип props рядом с компонентом |
| `function Badge({ children, tone = 'accent' })` | деструктуризация и значение по умолчанию |
| `children: ReactNode` | содержимое между тегами — обычный проп |
| `extra={<Badge>3</Badge>}` | слот: JSX в любом пропе |
| `ComponentProps<'button'>` + `...rest` | обёртка, которая принимает всё, что принимает тег |
| `{ status: 'soldOut' } \| { status: 'available'; inStock: number }` | union-props: TypeScript проверяет сочетания |

И несколько важных идей:

- данные текут сверху вниз: родитель передаёт props, ребёнок их только читает. Props передают ссылки — изменённый объект «испортится» у всех, кто его получил;
- компонент — чистая функция: те же props — тот же JSX, никаких изменений снаружи при рендере. React вправе вызвать компонент сколько угодно раз, и строгий режим это показывает;
- `key` не попадает в props, `defaultProps` у функций в React 19 не работают, `React.FC` не нужен;
- JSX-элемент — описание, а не вызов. React сам вызывает компоненты, обходя дерево в глубину, и для каждого элемента хранит файбер. Поэтому компоненты не объявляют внутри других компонентов и не вызывают как функции.

Карточка нарисована, но кнопка «В корзину» пока ничего не делает. Чтобы интерфейс отвечал на действия, компоненту нужна память между рендерами — **состояние** — и обработчики событий. С этого начинается глава 4: счётчик корзины, кнопка в карточке и общая корзина на всю страницу.
