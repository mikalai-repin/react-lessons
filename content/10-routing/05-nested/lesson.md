Избранное (глава 8) пока видно только сердечками на карточках. Покупателю нужна страница «мои отложенные игры». А в главе 14 рядом появятся «Мои заказы». Это **кабинет** — раздел из нескольких страниц с общим заголовком и вкладками:

```
/account            Кабинет  [Избранное] Настройки
/account/settings   Кабинет   Избранное [Настройки]
```

Заголовок и вкладки общие — их рисует макет раздела, а содержимое вкладки — дочерний маршрут. Ровно так, как макет магазина рисует шапку и `<Outlet />` (шаг «Маршруты»), — только на уровень глубже.

## Маршруты внутри маршрута

```tsx routes.tsx
      // Вложенные маршруты: макет кабинета и его вкладки
      {
        path: 'account',
        Component: AccountLayout,
        children: [
          { index: true, Component: FavoritesPage },
          { path: 'settings', Component: SettingsPage },
        ],
      },
```

По адресу `/account/settings` роутер находит **цепочку** маршрутов: корневой (`/`) → `account` → `settings`. Каждый рисует свой компонент, следующий — в `<Outlet />` предыдущего:

```
/account/settings
 └─ Layout           шапка, подвал
     └─ AccountLayout  «Кабинет», вкладки
         └─ SettingsPage
```

`/account` без продолжения — индексный маршрут: вкладка «Избранное».

## Макет раздела

```tsx account/AccountLayout.tsx
// Кабинет: общий заголовок и вкладки. Вкладка — дочерний маршрут
export function AccountLayout() {
  return (
    <Section title="Кабинет">
      <nav
        className={styles.tabs}
        aria-label="Разделы кабинета"
      >
        {/* Пути относительные: от адреса этого маршрута, /account */}
        {/* end: «Избранное» не горит на /account/settings */}
        <NavLink to="." end>
          Избранное
        </NavLink>
        <NavLink to="settings">Настройки</NavLink>
      </nav>
      <Outlet />
    </Section>
  );
}
```

Две новые вещи.

**Относительные пути.** `to` без `/` в начале считается **от маршрута, в котором нарисована ссылка**: `"settings"` в `AccountLayout` — это `/account/settings`, а `"."` — сам `/account`. Переименуете раздел в `/profile` — ссылки внутри менять не придётся. С `/` в начале путь абсолютный, от корня сайта.

**`end`.** NavLink активен на своём адресе **и на всех вложенных** — так «♥» в шапке (ссылка на `/account`) горит и на «Избранном», и на «Настройках»: мы в кабинете. Для вкладок это неверно — «Избранное» горело бы вместе с «Настройками». `end` требует точного совпадения.

## Вкладки

«Избранное» — игры, у которых горит сердечко, той же сеткой `GameGrid`; пустое избранное — подсказка:

```tsx account/FavoritesPage.tsx
// Вкладка «Избранное»: игры, отмеченные сердечком
export function FavoritesPage() {
  const favorites = useFavorites();
  const favoriteGames = games.filter((game) =>
    favorites.ids.includes(game.id),
  );
  if (favoriteGames.length === 0) {
    return (
      <p className="muted">
        Здесь будут игры, которые вы отметите сердечком ♡
      </p>
    );
  }
  return <GameGrid games={favoriteGames} />;
}
```

«Настройки» — переключатель темы. Кнопка «☾ Тёмная тема» переезжает сюда из шапки и становится флажком:

```tsx account/SettingsPage.tsx
// Вкладка «Настройки»: тема оформления
export function SettingsPage() {
  const { theme, toggleTheme } = useTheme();
  return (
    <label>
      <input
        type="checkbox"
        checked={theme === 'dark'}
        onChange={toggleTheme}
      />
      Тёмная тема
    </label>
  );
}
```

А «♥ N» в шапке из `<p>` становится `NavLink` на `/account` — стили для ссылки и активного состояния уже в `Header.module.css`, для вкладок — в `AccountLayout.module.css`.

::: task
1. В заготовках `account/` напишите `AccountLayout` (заголовок «Кабинет», вкладки `NavLink` с относительными путями, `<Outlet />`), `FavoritesPage` и `SettingsPage`.
2. В `routes.tsx` — маршрут `account` с дочерними: индексный — избранное, `settings` — настройки.
3. В `Header` «♥ N» — `NavLink` на `/account` с прежним классом и `title`; кнопку темы удалите (вместе с `useTheme`).
:::

## Что получилось

Отметьте сердечком «Остров сокровищ» и щёлкните «♥ 1» в шапке: `/account`, «Кабинет», вкладка «Избранное» выделена, в ней — «Остров». Щёлкните «Настройки»: `/account/settings`, выделена вторая вкладка, а «♥ 1» в шапке по-прежнему горит. Включите тёмную тему — магазин потемнел, как раньше от кнопки в шапке.

## Эксперименты

1. **Без `end`.** Уберите `end` у «Избранного» и откройте `/account/settings`: выделены обе вкладки. Верните.
2. **Абсолютный путь.** Напишите `to="/settings"` у «Настроек» и щёлкните: адрес `/settings`, «Такой страницы нет». Путь со слешем считается от корня сайта, а не от кабинета. Верните `"settings"`.
3. **Где `Outlet`.** Перенесите `<Outlet />` в `AccountLayout` выше `<nav>` — содержимое вкладки окажется над вкладками. Макет раздела сам решает, где показать дочерний маршрут, как `Layout` решает, где страница.

## Как в настоящем проекте

- Вложенность маршрутов повторяет вложенность интерфейса: общий кусок экрана — макет-родитель, меняющаяся часть — дети. Маршрут может быть и без `path` (только `Component` и `children`) — «макетный» маршрут: общая обёртка для группы страниц без своего сегмента адреса.
- Вкладки на маршрутах, а не на состоянии, когда у вкладки должен быть свой адрес: ссылкой поделиться, ⟳ не сбросит, «назад» вернёт прошлую вкладку. Вкладки внутри одной карточки (описание / характеристики) — обычное состояние.
- В главе 14 кабинет станет закрытым: вкладка «Мои заказы» и вход перед ней — для всего раздела сразу, на уровне маршрута `account`.
