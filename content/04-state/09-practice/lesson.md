Корзина хранится в `App`, но покупатель видит от неё только число в шапке. Ни убрать лишнее, ни узнать сумму он не может. Соберите мини-корзину над каталогом: позиции с количеством, итог и условие бесплатной доставки.

Стили готовы в `cart/MiniCart.module.css`, в `cart/MiniCart.tsx` — только комментарий `TODO`. В `App.tsx` метки `TODO` показывают, где нужен новый код.

::: task
1. В `cart/MiniCart.tsx` объявите тип props: `items` — позиции корзины (`CartItem[]`), `games` — игры каталога, и три обработчика, которые принимают `gameId`: `onIncrease`, `onDecrease`, `onRemove`.
2. Компонент `MiniCart` рисует раздел `<Section title="Корзина">`. Пустая корзина — текст «Корзина пуста — добавьте игру из каталога» (классы `muted` и `styles.empty`).
3. Непустая — `<Badge tone="dark">` с общим числом штук в `extra` раздела и список `<ul className={styles.list}>`. Позиция `<li className={styles.item}>`: название игры (`styles.title`), блок `styles.quantity` с кнопками «−» и «+» и числом в `<output>` между ними, сумма позиции (`styles.sum`) и кнопка «×». Все четыре кнопки — `<button type="button" className={styles.step}>`.
4. «+» выключен, когда в корзине столько штук, сколько на складе. У кнопок из одних символов должен быть `aria-label`: «Убрать одну», «Добавить ещё», «Убрать «Название»».
5. Под списком — `Итого: …` (`styles.total`) и строка доставки (`muted` и `styles.delivery`): от 5000 ₽ — «Доставка бесплатно», меньше — «До бесплатной доставки — N ₽». Порог — в константу `FREE_DELIVERY`.
6. В `App.tsx` напишите `handleDecrease` (минус одна штука; последняя — позиция исчезает) и `handleRemove` (убрать позицию целиком). Импортируйте `MiniCart` и нарисуйте его после акции: `onIncrease` — уже готовый `handleAdd`.
:::

::: hint Подсказка 1: с чего начать
Начните с `App.tsx`: два обработчика устроены как `handleAdd` из шага про массивы — функция обновления, которая возвращает **новый** массив. Затем в `MiniCart` нарисуйте пустое состояние и проверьте его на экране, и только потом список.
:::

::: hint Подсказка 2: обработчики в App
Убрать позицию — `filter`: оставить все позиции, у которых `gameId` не тот. Минус одна — сначала `map` (у нужной позиции новый объект с `quantity - 1`), затем `filter` позиций, где `quantity > 0`. Так «−» на последней штуке убирает позицию без отдельного `if`.
:::

::: hint Подсказка 3: позиции вместе с играми
В позиции только `gameId`, а для строки нужны название, цена и остаток. Соберите их при рендере: `items.map((item) => ({ ...item, game: games.find((game) => game.id === item.gameId)! }))`. Восклицательный знак говорит TypeScript, что игра найдётся всегда: в корзину попадают только игры каталога. Итого — `reduce` по этому массиву: `sum + line.game.price * line.quantity`.
:::

::: hint Подсказка 4: обработчики с аргументом
Кнопке нужна функция без аргументов, а `onDecrease` ждёт `gameId`. Передайте стрелку: `onClick={() => onDecrease(game.id)}`. Ключ позиции — `game.id`: у позиций он уникален, а сами позиции добавляются и исчезают — индекс здесь не годится.
:::

::: hint Подсказка 5: строка доставки
Тернарный оператор прямо в JSX, вторая ветка — шаблонная строка:

```tsx
{total >= FREE_DELIVERY
  ? 'Доставка бесплатно'
  : `До бесплатной доставки — ${formatPrice(FREE_DELIVERY - total)}`}
```

`formatPrice` — из `shared/format.ts`. Два класса в одном `className` — тоже шаблонной строкой: `` className={`muted ${styles.delivery}`} ``.
:::

## Проверьте себя

- При запуске под акцией — «Корзина» и «Корзина пуста — добавьте игру из каталога».
- Добавьте «Остров сокровищ» в «Хитах», ещё раз — во «Всех играх», и «Нарды»: в мини-корзине бейдж «3», «Остров сокровищ − 2 + 3 980 ₽» и «Нарды − 1 + 2 590 ₽», «Итого: 6 570 ₽», «Доставка бесплатно». В шапке «Корзина: 3», под обоими «Островами» — «В корзине: 2 шт.».
- «Ночной экспресс» в корзине три раза: «+» у него в мини-корзине выключен, как и «В корзину» в обеих карточках.
- «−» у «Острова» дважды: позиция исчезла, у карточек «Острова» пропала строка «В корзине». «×» у «Ночного экспресса»: в корзине одни «Нарды», «Итого: 2 590 ₽», «До бесплатной доставки — 2 410 ₽». «×» у «Нард» — корзина снова пуста.
- Консоль пуста, ошибок типов нет.

## Итоги главы

Магазин начал отвечать на действия покупателя. Корзина живёт в `App` и расходится по шапке, карточкам и мини-корзине через props.

| Запись | Что делает |
|---|---|
| `onClick={handleAddClick}` | передать обработчик — саму функцию, без скобок |
| `onClick={() => onRemove(game.id)}` | обработчик с аргументом — стрелкой |
| `e.preventDefault()`, `e.stopPropagation()` | отменить действие браузера, остановить всплытие |
| `const [cart, setCart] = useState<CartItem[]>([])` | состояние: значение этого рендера и сеттер |
| `setQuantity((q) => q + 1)` | функция обновления: новое значение из предыдущего |
| `[...items, x]`, `items.map(…)`, `items.filter(…)` | новый массив вместо изменения старого |
| `{ ...item, quantity: item.quantity + 1 }` | новый объект вместо изменения старого |
| `onAdd={() => handleAdd(game.id)}` | событие вверх: ребёнок сообщает, родитель меняет состояние |

И несколько важных идей:

- экран меняется только после рендера, а рендер запускает сеттер состояния. Обычные переменные не переживают рендер и ничего не запускают;
- состояние — снимок: в рендере и его обработчиках значение не меняется, новое появится в следующем рендере. Обновления копятся в очереди и обрабатываются пакетом — один рендер на обработчик;
- состояние не изменяют, а заменяют: React сравнивает старое и новое через `Object.is`, и изменённый «на месте» объект для него — тот же самый;
- общее состояние поднимают к ближайшему общему родителю — так у данных один источник истины;
- рендер вызывает компоненты и сверяет элементы, фиксация вносит в DOM только отличия.

Пока корзина умеет одно: считать штуки. Но в магазине есть и другое состояние: что ввели в поиск, какие фильтры выбраны, какая сортировка. В главе 5 появятся поля ввода — управляемые и неуправляемые, — правила, что хранить в состоянии, а что вычислять, и `useReducer`, в который переедет логика корзины.
