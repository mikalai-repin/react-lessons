# React — интерактивный курс

Интерактивный учебник по **React 19** и его экосистеме на русском: слева урок, в центре редактор (`.tsx`, `.ts`, `.css`), справа живое приложение в iframe с адресной строкой, консолью и вкладкой «Сеть». Сквозной проект — магазин настольных игр «Ход конём». Цель — уровень senior: «как», «почему» и «что под капотом». Ученик знает JS/TS и веб, но не писал на React. Платформа и формат — как у `../angular-learn` (образец, если здесь чего-то не хватает).

## Как читать документацию

Документы большие (вместе — больше 30 тысяч слов) и растут с каждой главой. **Не читайте их целиком и «на всякий случай»**: только то, что нужно под задачу, а в длинных файлах — только свой раздел (`grep -n` по заголовку или имени API, затем `Read` с `offset`/`limit`). В начале каждого документа — строка «Когда читать».

| Задача | Читать | Не нужно |
|---|---|---|
| Любая — сначала | `docs/roadmap.md`, раздел «Следующий шаг» — он перечисляет нужные разделы | остальное |

## Правила, которые действуют всегда

- **Только современный React 19.3**: функции и хуки, `ref` как проп, `<Context>` как провайдер, Actions, `use()`. Устаревшее — только во врезках «Вы встретите в старом коде» (список — `docs/modern-react.md`, «Запрещено»).
- **Факты об API — по типам и исходникам установленных версий в `node_modules` и запуском, не по памяти** (в памяти модели — React 16–18, React Router 5/6, antd 4/5, React Query 3/4, Redux без Toolkit). Проверенное — строкой в `docs/facts/<тема>.md` с источником.
- **Каждое утверждение и эксперимент из текста — проверены запуском**; «сколько раз отрендерится», «порядок эффектов», «отменится ли запрос» — только по логу.
- **Код шагов — коммитами в ветке главы** (`authoring/<глава>/`, один коммит — один шаг); `start/` и `solution/` в `content/` руками не правим, их раскладывает `npm run chapter export`; текст — прямо в `content/<глава>/<шаг>/lesson.md`.
- **Библиотека — после того, как ученик сделал то же самое руками.** Стек: React Router 8, Zustand, TanStack Query, React Hook Form + Zod, Ant Design 6, Redux Toolkit, Vitest + Testing Library.
- Код ученика выполняется в браузере без сборщика (TS → JS в воркере, import map, один экземпляр React). **TypeScript 6.0**, не 7.
- Тексты и комментарии — на русском, идентификаторы — на английском.

## Команды

- `npm run dev` — **http://localhost:5190** (5173/5174 — PixiJS, 5180 — Angular, 5200 — Vue); проверки требуют запущенного сервера и Chrome
- `npm run chapter new|open|status|export|fix|sync-base <глава>` — код шагов главы (`docs/authoring-process.md`, раздел 2)
- `npm run validate` — структура, цепочка шагов, сборка и типы всех шагов; `npm run build`; `npx prettier --check .`
- `node tools/e2e/run-dir.mjs <папка шага> [адрес] [мс]` — шаг в чистом превью
- Остальные проверки (`run-chapter`, `exp`, `checks/*`, `step-checks`, `lesson-code`, `quiz`) и когда их запускать — `docs/authoring-process.md`, «Команды и проверки»

## Работа с автором

- Пользователь — автор курса, общение на русском. Перед большой работой — короткий план; по ходу — короткие сообщения; в конце — что сделано, как проверено, что осталось.
- После главы — журнал `docs/chapters/<глава>.md`, `docs/roadmap.md` (статус + «Следующий шаг») и строка «Текущий статус» здесь. «Следующий шаг» пишется так, чтобы следующий агент знал, **какие разделы каких файлов** ему нужны.
