# Глава 9 «Состояние приложения» — 9 шагов

Журнал главы: шаги — как получилось на самом деле (а не по плану), код магазина к концу главы, технический долг, опоры для следующей главы.

Ветка `chapter/09-app-state`; все утверждения и эксперименты проверены запуском и `tsc` (`checks/ch09-app-state.mjs`, 49 проверок, разделы — `ONLY=9.x`), квиз — 15 вопросов, у практикума — `check.ts` и две типичные ошибки в `step-checks.mjs`. До главы — Jotai 3.0.1 в vendor превью (`jotai`, `jotai/utils`), типы в Monaco (`typesOf` понимает условие `types@>=5.5`), `checks/preview.mjs` +3. Отличия от плана: добавлен «Под капотом» (9.7) перед картой решений (9.8) и практикумом (9.9); уведомление «Добавлено» живёт в сторе (с 9.5 — срез `toastSlice`); **избранное осталось в контексте** (план предлагал Zustand) — в карте решений это показано как равноправный вариант; лимит склада проверяется в сторе с уведомлением, поэтому `disabled` по остатку из кнопок убран.

- 9.1 «Свой стор» (свой старт: заготовки `store/cartStore.ts`, `cart/CartToast.tsx`, готовый `CartToast.module.css`) — `state` и `listeners` модуля, `subscribe`, `setState` (новый объект), `dispatch` через `produce` + `cartReducer`, `showToast` с таймером модуля, `cartActions`, `useCartStore(selector)` на `useSyncExternalStore`; `CartProvider`/`CartContext` удалены (`removedInSolution`). Лог: «В корзину» у «Острова» — Header 2, MiniCart 2, GameCard 4; у «Драконьей почты» — GameCard 2; погасло уведомление — 0; подписки 18/9 при запуске, 0 при щелчке; `cartActions.add` из таймера в `main.tsx`; селектор с объектом — бесконечный цикл.
- 9.2 «Zustand» — `create<CartState>()((set) => …)`, действия в состоянии, `useShallow` в `MiniCart`. Эксперименты: без `useShallow` — цикл; `useCartStore()` без селектора — MiniCart 2 при погасшем уведомлении; `getState().add` + `subscribe` (две строки: два `set`, рендер один); `set(…, true)` — TS2769; `::: legacy` — второй аргумент хука, `zustand/traditional`.
- 9.3 «Сохранение» — `persist` с `name: 'cart'` (не `hod-konem-cart` демо), `partialize`, `version: 1`, `migrate` — история на настоящей ошибке «уведомление застряло после ⟳». Эксперимент: `version: 2` без `migrate`.
- 9.4 «Производное состояние» (свой старт: заготовка `store/cartSelectors.ts`) — `selectCartCount`, `summarizeCart(items, games)` (позиции, итог, `savings`, `toFreeDelivery`), строка «Скидка по акции». Эксперименты: итоги в селекторе — цикл, с `useShallow` — тоже.
- 9.5 «Срезы и devtools» (свой старт: заготовки `cartSlice.ts`, `toastSlice.ts`) — `StateCreator<CartState, CartMiddlewares, [], …>`, `get().showToast`, `devtools(persist(…), { name: 'Корзина' })`, имена действий `cart/${type}`, `toast/shown`/`hidden`. Журнал проверен поддельным расширением (`anonymous` от `persist` первым); без мутатора `devtools` — TS2554.
- 9.6 «Атомы» (свой старт: заготовка `catalog/filterAtoms.ts`) — `filterAtom` (атом с записью, сбрасывает `limitAtom`), четыре атома полей, производный `filtersAtom`, `resetFiltersAtom`; `CatalogFilters` только с `ref`, в `App` — `useAtomValue`/`useAtom`/`useSetAtom`, `handleFiltersChange` удалён. Эксперименты: пересчёт `filtersAtom` (1 при запуске, 1 на букву, 0 при открытии игры), `queryAtom` в шапке.
- 9.7 «Под капотом: как устроен стор» (`noSolution`) — `vanilla.mjs` и `react.mjs` целиком, `Object.keys(useCartStore)`, демонстрация в `main.tsx` без StrictMode: «Эффект: 0» против «useSyncExternalStore: 1»; разрыв и проверка согласованности; почему снимок кешировать; Jotai — `useReducer` со сверкой (тот же опыт — «Jotai: 1»).
- 9.8 «Карта решений» (`noSolution`) — дерево вопросов, сравнение мест хранения, таблица «наш магазин: где сейчас — куда дальше», признаки ошибки, упражнение с ответами в `::: hint`.
- 9.9 «Практикум: лимиты склада и промокод» (свой старт: `data/promo.ts`, `.promo`/`.promoError` в `MiniCart.module.css`) — правило склада в `add` («Больше нет: на складе N шт.»), `promo` + `applyPromo` (ошибки «Нет такого промокода», «Промокод действует от 3 000 ₽»), снятие в `dispatch` ниже порога («Промокод снят: …»), `summarizeCart(…, promo)` → `promoDiscount`, `payable`, форма в `MiniCart` (ошибка — локальный `useState`), `promo` в `partialize`; `check.ts`; «Итоги главы».
