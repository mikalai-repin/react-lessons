# Глава 11 «Данные с сервера» — 12 шагов

Журнал главы: шаги — как получилось на самом деле (а не по плану), код магазина к концу главы, технический долг, опоры для следующей главы.

Ветка `chapter/11-server-data`; все утверждения и эксперименты проверены запуском и `tsc` (`checks/ch11-server-data.mjs`, 94 проверки, разделы — `ONLY=11.x`; лог стенда 11.11 сверяется прямо с `lesson.md`), квиз — 15 вопросов, у практикума — `check.ts` и типичная ошибка в `step-checks.mjs`. API — по исходникам `@tanstack/query-core`/`react-query` 5.104.1 и `react-error-boundary` 6.1.6; документация промисов в `loader` — `node_modules/react-router/docs/how-to/suspense.md`.

До главы: учебный бэкенд перенесён из angular-learn целиком (40 игр, обложки, отзывы, фильтры `rating`/`onSale`, JWT-вход, `tokenTtl` — пригодится в главе 14; отзыв без входа — «Гость»), своё — `POST /api/subscribe` и новые настройки шага `slow` (добавочная задержка адреса) и `fail` (адрес всегда 500) — без них гонку и сбой одних отзывов не воспроизвести. `react-error-boundary` 6.1.6 — в vendor (`PREVIEW_MODULES`), типы — в Monaco (пакет без `exports`: `monaco.ts` берёт `types`), `checks/preview.mjs` +2. `checks/preview.mjs` ждёт «Найдено игр: 40».

Отличия от плана: шагов 12, а не 9 + практикум + «под капотом»: гонка — на каталоге (смена категории), а не на `:id`; «Изменения» разделены на `useMutation` (11.8) и оптимистичное обновление (11.9); Suspense-режим и связка с `loader` (11.7) — до мутаций, потому что мутации инвалидируют кэш отзывов, а отзывы должны жить в Query; пагинации «1 2 3» нет — `keepPreviousData` показан на смене фильтров, порции — на `useInfiniteQuery`; `prefetchQuery`/`ensureQueryData` в 5.104 устарели — вместо них `queryClient.query`; обзор SWR/RTK Query/axios — в шаге «Под капотом»; практикум — не «каталог целиком» (каталог готов к 11.10), а «Хиты» и «Избранное» с сервера и удаление `data/games.ts`. За кадром (старт 11.1): корзина хранит снимок игры `CartGame` (`add(game)`, `summarizeCart(items, promo)`, `persist` версии 2 с пустой корзиной для старых записей), заказ отправляет только `gameId` и `quantity`.

- 11.1 «Учебный бэкенд» (свой старт: снимок игры в корзине, заготовки `api/client.ts`, `api/games.ts`) — таблица API, вкладка «Сеть», `ApiError` + `apiGet` (`fetch` не бросает на 404), `fetchGame`, `gameLoader` одной строкой, `RouteError` знает `ApiError`. Эксперименты: без проверки `ok` — `TypeError: Cannot destructure property 'min'…`, задержка 3000.
- 11.2 «fetch в эффекте» (свой старт: `filtersToApi`, `fetchGames`, `Page<T>`; `slow` у `category=family`) — `useState` + `useEffect` с `AbortController`, три состояния, `LoadMore`/`limit`/`filterGames` удалены. StrictMode — «отменён» + 200; гонка без очистки — выбраны «Детские», на экране семейные; список того, чего не умеет эффект.
- 11.3 «Suspense и use» (свой старт: `Review`, `fetchReviews`, `formatDate`, `ReviewsSkeleton` и стили; `slow` у отзывов игры 1) — промис отзывов из `loader` без `await`, `use`, `<Suspense>`, крошка `data?.game.title`. Эксперименты: без `Suspense` — `HydrateFallback` при заходе и старый экран при переходе; водопад (1 → 2 с на `/games/2`); `use(fetchReviews(id))` в рендере — бесконечные запросы без предупреждения.
- 11.4 «Границы ошибок» (старт = прошлый шаг; `fail` у отзывов игры 2) — класс-граница в тексте, `react-error-boundary` с `resetKeys={[reviews]}` и повтором через `revalidate`, `reviews.catch(() => {})` от необработанного отклонения. Эксперименты: без `resetKeys` ошибка «переезжает» на следующую игру, без `catch` — вторая ошибка, своя граница `OwnBoundary`.
- 11.5 «TanStack Query» (свой старт: заготовка `api/queryClient.ts`) — провайдер, `useQuery` в каталоге, шапка — тот же ключ (один удачный запрос), `Header` без пропа `count`. Эксперименты: 4 ответа 500 и ~8 с, без провайдера — `No QueryClient set…`; таблица умолчаний.
- 11.6 «Ключи и кэш» (свой старт: `.results[aria-busy]`) — `gameKeys`, `gamesQuery` через `queryOptions`, `staleTime` 30 с в `defaultOptions`, `keepPreviousData` + `isPlaceholderData`. Эксперименты: ключ без параметров, `STALE_TIME = 0`, без `keepPreviousData`.
- 11.7 «Query и роутер» (старт = прошлый шаг; `fail` у отзывов игры 2) — `gameQuery`/`reviewsQuery`, `loader`: `queryClient.query(reviewsQuery).catch(noop)` + `query({ …gameQuery, staleTime: 'static' })`, `useSuspenseQuery` в странице и `Reviews`, `useQueryErrorResetBoundary` + `onReset`, `resetKeys={[id]}`. Ошибка предзагрузки — сразу (у `query` `retry: false`), «Повторить» — только отзывы (4 попытки хука). Без `onReset` — повтора нет.
- 11.8 «Изменения на сервере» (свой старт: форма отзыва — `game/ReviewForm.tsx` с выбором оценки, `apiPost`, `postReview`, `NewReview`) — `useMutation`, `invalidateQueries` с `return` из `onSuccess`, `mutate(…, { onSuccess })` для черновика, «Отправляем…», ошибка. Эксперименты: без `return`, 500 — одна попытка, без инвалидации отзыва нет и после перехода.
- 11.9 «Оптимистичное обновление» (старт = прошлый шаг; задержка 1500) — `onMutate` (`cancelQueries`, снимок, `setQueryData`), `onError` — откат, `onSettled` без `return`; ключ из `reviewsQuery(id).queryKey` — тип. Эксперименты: откат, без `onError` — «призрак», `return` в `onSettled` — ошибка позже, ключ без типа — TS2488.
- 11.10 «Бесконечный список» (старт = прошлый шаг) — `PORTION = 6`, `gameKeys.infinite`, `gamesInfiniteQuery` (`infiniteQueryOptions`), `useInfiniteQuery` + `LoadMore` с проверкой `isFetchingNextPage`. Эксперименты: без проверки — «отменён» + 200, общий ключ с шапкой — «в каталоге undefined игр».
- 11.11 «Под капотом: как устроен кэш запросов» (`noSolution`, стенд в тексте) — схема `QueryClient`/`QueryCache`/`Query`/`QueryObserver`, `hashKey`, лог событий кэша при запуске (StrictMode: `setState` + `observerRemoved`), `refetchQueries` по началу ключа, structural sharing и отслеживание полей (0 / 2 / 4 рендера шапки), повторы и сеть; обзор SWR, RTK Query, axios против `fetch`.
- 11.12 «Практикум: магазин без локального каталога» (свой старт: «Следующая игра» по `total` из кэша шапки, экспорт `HIT_RATING`) — «Хиты» через `gamesQuery('rating=4.6&sort=rating&size=6')` («Хиты 11», 6 карточек), «Избранное» через `useQueries` + `gameQuery`, `data/games.ts` удалён (`removedInSolution`); `check.ts`; «Итоги главы».

Технический долг: «Следующая игра» опирается на то, что id игр сервера идут подряд 1…total (в главе 18 админка удаляет игры — пересмотреть, например, соседей из списка каталога); `PromoBanner` по-прежнему знает про «Остров сокровищ» и «Нарды» текстом; промокод и склад в корзине — локальные правила (сервер проверяет остаток при заказе — `409`); `GameDetails` получает игру пропом, а не из кэша (после мутации игры в главе 18 — через `gameQuery`).
