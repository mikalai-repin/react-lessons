Порядок как в плане, «Под капотом» (6.10) — перед практикумом. До главы найдено и исправлено в платформе: `<form method="dialog">` перезапускал превью (`preview-runtime.js`, проверка в `checks/platform.mjs`). Шаг 6.6 — рефакторинг: коммит `start` добавляет три лишних эффекта, решение = код 6.4/6.5.

- 6.1 «useRef: значение без рендера» (свой старт: `.toast` в `App.module.css`) — уведомление «Добавлено: …» (`toast`, `TOAST_MS = 2500`, `showToast`, id таймера в `useRef<number | null>`), `role="status"`. Эксперименты: `let` вместо ссылки — второе уведомление пропадает через ~1 с; лог «до/после» — ссылка меняется сразу, `toast` — снимок; `::: deep` — `mountRef`.
- 6.2 «Ссылки на DOM» — `searchRef` в `App`, `ref?: Ref<HTMLInputElement>` в props `CatalogFilters`, `handleReset` с `focus()`. Эксперименты: без `focus()` — фокус на `<body>`; `ref` без типа (TS2322, React молчит); `searchRef.current` при рендере — `null` ×2; колбэк-ref с очисткой (StrictMode, на каждую букву, уход), без `return` — `null`, неявный `return` — TS2322; `::: legacy` — `forwardRef`.
- 6.3 «useImperativeHandle» (свой старт: действие `cleared` в редьюсере, `handleClear` + `onClear` в `App` и типе `MiniCart`, стили окна и `.clear`, заготовка) — `shared/ConfirmDialog.tsx` (`ConfirmDialogHandle { open }`, `<dialog>` + `showModal()`, `<form method="dialog">`, `returnValue`, `onClose`), «Очистить корзину» в `MiniCart`. Эксперименты: `ref: { open: ƒ open() }`, `close()` — TS2339, `show()` — немодальное, Esc не закрывает.
- 6.4 «useEffect» (свой старт: `data/sale.ts` — `SALE_ENDS` через 2 ч после запуска, `formatDuration`, стили, заготовка) — `shared/Countdown.tsx` (`now` с инициализатором, `finished`, интервал с очисткой, зависимость `[finished]`), на странице игры при `oldPrice`. Эксперименты: лог старт/стоп (StrictMode, уход, `key`), без массива — перезапуск каждую секунду, акция 3 с — «Акция закончилась», `async`-эффект (TS2345 + ошибка React).
- 6.5 «Эффекты в строгом режиме» (`noSolution`) — схема имитации, без очистки (тики 2/с, после ухода, 6 после трёх заходов; без StrictMode — 3), флажок в ref (таймер стоит), таблица «настройка — очистка», отменённый запрос демо 1.1.
- 6.6 «Возможно, эффект не нужен» (свой старт с тремя эффектами: итог `MiniCart` в состоянии, сброс отзыва эффектом без `key`, уведомление через `lastAdded`) — решение убирает все три. Лог: 4 рендера `MiniCart` и «Итого: 0 ₽» в DOM; 4 рендера `GameDetails` и «13 / 300» у новой игры; второй щелчок по той же игре не продлевает уведомление. Таблица «если эффект… — вместо него», цепочки, правило `set-state-in-effect`.
- 6.7 «useEffectEvent» (свой старт: `shared/analytics.ts` — `track` в консоль) — `VIEW_DELAY = 3000`, `onView = useEffectEvent((gameId) => track('просмотр', { gameId, inCart: quantity }))`, эффект с `setTimeout` и `[game.id]`. Лог трёх вариантов: `[game.id]` без события — `inCart: 0` (устаревшее замыкание, `exhaustive-deps`), `[game.id, quantity]` — событие через 4 с и второй «просмотр», решение — одно через 3 с с `inCart: 1`; вызов при рендере — ошибка; `::: legacy` — ссылка с последним значением.
- 6.8 «useLayoutEffect и порталы» (свой старт: `Tooltip.module.css`, `transform` у `.card:hover`, заготовка) — `shared/Tooltip.tsx` (`useLayoutEffect` + `getBoundingClientRect`, `Math.min` по правому краю, `createPortal` в `body`, `tabIndex`, `useId` + `aria-describedby`), бейдж «Хит» в `GameCard`. Эксперименты: без ограничения — сжата до ~100 px, без портала — уехала вниз карточки, `useEffect` + CPU ×20 — кадр до замера.
- 6.9 «Внешние хранилища» (свой старт: стили, заготовка) — `layout/OfflineBanner.tsx` (`subscribe`/`getSnapshot` вне компонента, `useSyncExternalStore`, `role="alert"`), первым в `App`. Эксперименты: рендеры и подписки, поддельное `offline` — ни одного рендера, новый объект из `getSnapshot` — бесконечный цикл.
- 6.10 «Под капотом: когда выполняются эффекты» (`noSolution`) — датчик `Probe`/`Demo` в `main.tsx` без StrictMode (код урока проверяется прямо из `lesson.md`): запуск, щелчок, наведение, удаление; микрозадача из layout-эффекта; схема фаз.
- 6.11 «Практикум: „Показать ещё“» (свой старт: `LoadMore.module.css`, заготовка) — `catalog/LoadMore.tsx` (`IntersectionObserver` в эффекте, `disconnect`, `onLoad` через `useEffectEvent`, кнопка), в `App` — `PAGE_SIZE = 3`, `limit`, `shownGames`, `handleFiltersChange` сбрасывает порцию (и `handleReset`); «Итоги главы».

Код магазина к концу главы: `main.tsx` (как в главе 1), `App.tsx` (~230 строк: + `toast`/`toastTimer`/`showToast`, `searchRef` + `handleReset`, `handleClear`, `limit` + `shownGames` + `handleFiltersChange`, `OfflineBanner`, `LoadMore`, уведомление `role="status"`), `cart/MiniCart.tsx` (+ «Очистить корзину» и `ConfirmDialog`), `catalog/CatalogFilters.tsx` (+ `ref`), `catalog/LoadMore.tsx` + `.module.css`, `data/sale.ts`, `game/GameDetails.tsx` (+ `Countdown`, аналитика просмотра), `layout/OfflineBanner.tsx` + `.module.css`, `shared/ConfirmDialog.tsx` + `.module.css`, `shared/Countdown.tsx` + `.module.css`, `shared/Tooltip.tsx` + `.module.css`, `shared/analytics.ts`, `shared/format.ts` (+ `formatDuration`), `shared/GameCard.tsx` (+ подсказка у «Хит») и `.module.css` (+ `transform` при наведении), `store/cartReducer.ts` (+ `cleared`), остальное — как в главе 5.
