# Глава 10 «Роутинг» — 14 шагов

Журнал главы: шаги — как получилось на самом деле (а не по плану), код магазина к концу главы, технический долг, опоры для следующей главы.

Ветка `chapter/10-routing`; все утверждения и эксперименты проверены запуском и `tsc` (`checks/ch10-routing.mjs`, 82 проверки, разделы — `ONLY=10.x`; код стенда 10.13 берётся прямо из `lesson.md`), квиз — 15 вопросов, у практикума — `check.ts` и типичная ошибка в `step-checks.mjs`. API — по типам и по документации v8 в самом пакете (`node_modules/react-router/docs`). До главы: учебный бэкенд получил `POST /api/subscribe` (201 / 400 / 409). Отличия от плана: каталог отделён от главной в 10.4 (вместе с фильтрами в адресе), а не в 10.1–10.2; `useFetcher` — свой шаг (10.8, подписка); ленивым сделано оформление, а не кабинет (`lazy` возвращает и `action`); «Навигация и UX» — `useBlocker` на оформлении, `ScrollRestoration`, `viewTransition`; обзор TanStack Router — раздел шага «Под капотом». Jotai ушёл из кода магазина (фильтры — в адресе), тема переехала из шапки в «Настройки» кабинета.

- 10.1 «Маршруты» (свой старт: заготовки `routes.tsx`, `layout/Layout.tsx`, `catalog/HomePage.tsx`, `cart/CartPage.tsx`, `layout/NotFoundPage.tsx`, готовые `Layout.module.css`, `HomePage.module.css`) — режимы роутера, `createBrowserRouter`, `RouterProvider` из `react-router/dom`, `Layout` + `<Outlet />`, `index`, `*`; `App.tsx` удалён. Эксперименты: без `Outlet`, без `*` («Unexpected Application Error!»), макет живёт между страницами (поле подписки, 0 рендеров `Layout`).
- 10.2 «Ссылки» (свой старт: стили ссылок шапки, цвет `a` в `styles.css`) — логотип `Link`, корзина `NavLink` (`aria-current`), ссылки на 404 и в пустой корзине. Эксперименты: без перезапуска, `<a href>` перезапускает превью, `NavLink to="/"` не активен на `/cart`.
- 10.3 «Параметры» (свой старт: заготовка `game/GamePage.tsx`, `.titleLink`) — `games/:id`, `useParams` (строка), «Игра не найдена», название карточки — `Link`, `selectedId`/`onSelect` удалены, «← Назад» — `useNavigate` с `location.key === 'default'`, «Следующая игра →» — `Link`. Эксперименты: без `key` «Спасибо!» переезжает, `game.id === id` — TS2367.
- 10.4 «Состояние в URL» (свой старт: заготовка `CatalogPage.tsx`, `.empty`) — `/catalog`, `filtersFromParams`/`filtersToParams` с проверкой значений, `useSearchParams`, `replace` только для поиска, `CatalogFilters` снова с props, `filterAtoms.ts` удалён; ссылки «в каталоге N игр» и «Все семейные игры →». Эксперименты: история, без `replace` +3 записи, `?category=bogus` без проверки — пусто, а в списке «Все».
- 10.5 «Вложенные маршруты» (свой старт: заготовки `account/*`, стили вкладок и «♥») — `account` с индексным «Избранное» и `settings`, относительные `to`, `end`, «♥ N» — `NavLink` на `/account`, тема — флажок в «Настройках». Эксперименты: без `end`, `to="/settings"` — 404.
- 10.6 «Загрузка данных» (свой старт: `aria-busy` в `Layout.module.css`; `backend.latency` 1000) — `gameLoader` с `request.signal`, `useLoaderData<typeof gameLoader>`, `HydrateFallback`, `useNavigation` + `aria-busy`. Эксперименты: уход до ответа — запрос отменён, без `HydrateFallback` — пусто и предупреждение, второй запрос при повторе.
- 10.7 «Изменение данных» (свой старт: заготовки `checkout/*`, стили формы и `a.button`; `clear` в сторе молча снимает промокод) — `checkoutAction` (`POST /api/orders`, ошибка — `{ error }`, успех — `clear()` + `redirect`), `Form method="post"`, `useActionData`, `submitting`, `OrderDonePage`, «Оформить заказ» в корзине. Эксперименты: 409 при втором заказе, `required` без запроса, «назад» — «0 шт. на 0 ₽» (мотив 10.11).
- 10.8 «useFetcher» (старт = прошлый шаг) — ресурсный маршрут `subscribe`, `subscribeAction` в `Footer.tsx`, `fetcher.Form`, `fetcher.state`/`data`. Эксперименты: после `action` фетчера — перезагрузка `GET /api/games/4`, обычная `Form` — пустая страница `/subscribe`.
- 10.9 «Ошибки и 404» (свой старт: заготовка `layout/RouteError.tsx`) — `throw data(null, { status })` в `gameLoader`, `RouteError` (`useRouteError`, `isRouteErrorResponse`, 404 → `NotFoundPage`, `useRevalidator`), граница у корня и у маршрута без `path`. Эксперименты: ошибка рендера (два сообщения в консоли), только корневая граница — без шапки, без границ — «Unexpected Application Error!».
- 10.10 «Ленивые маршруты» (старт = прошлый шаг) — `lazy` у `checkout` с `Component` и `action`, статический импорт удалён. Эксперименты: лог модуля один раз, задержка 1 с — `aria-busy`, прямой заход — `HydrateFallback`.
- 10.11 «Защита маршрутов» (старт = прошлый шаг) — `loader` с `redirect('/cart')` у `checkout`. Эксперименты: «гард» `<Navigate>` — 2 рендера до перехода, `lazy` грузится и при `redirect`.
- 10.12 «Навигация и UX» (свой старт: стиль `.leave`) — `dirty` + `useBlocker` (другой путь), плашка «Уйти?», `ScrollRestoration`, `viewTransition` у ссылки карточки. Эксперименты: без `ScrollRestoration`, `() => dirty` блокирует отправку.
- 10.13 «Под капотом: как роутер ведёт переход» (`noSolution`) — стенд в `main.tsx`: `matchRoutes` и очки (`rankRouteBranches`), параллельные загрузчики (~1 с), переход между соседями — только новый загрузчик, быстрая смена — `abort`, побеждает последний; схема жизни перехода; обзор TanStack Router.
- 10.14 «Практикум: хлебные крошки» (свой старт: заготовка `Breadcrumbs.tsx`, стили) — `handle: { crumb }` у маршрутов, `useMatches` + предикат `hasCrumb`, `loaderData` (защита от `undefined` на 404), `<Breadcrumbs />` в макете; `check.ts`; «Итоги главы».

Опоры для главы 11: каталог — всё ещё локальный `data/games.ts`, а страница игры — уже `/api/games/:id` через `loader`; в 10.6 обещано: `useEffect` + `fetch` с гонкой (11.x), кэш (второй запрос при повторе), `queryClient.ensureQueryData` в `loader`, `<Suspense>` + `use` для медленной части.
