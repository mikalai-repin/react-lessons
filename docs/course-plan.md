# Программа курса

> **Состояние:** рабочий план (2026-10-06). Состав шагов уточняется при написании главы; расхождения фиксируются в `docs/authoring-process.md`, раздел «Фактическое состояние», как в angular-learn. Все API в таблицах перед написанием главы сверяются с установленными версиями (`docs/modern-react.md`) — пометка «(проверить)» означает, что статус API ещё не подтверждён.

Курс состоит из **трёх частей**:

1. **Основы** (главы 1–8). Компоненты, JSX, состояние, эффекты, хуки, контекст. На выходе — витрина магазина на одной странице: карточки, фильтры, корзина в шапке. Только React, без сторонних библиотек.
2. **Приложение** (главы 9–20). Глобальное состояние, роутинг, данные с сервера, конкурентный React и Actions, формы, авторизация, Ant Design, производительность, тесты, админка, Redux Toolkit, паттерны. На выходе — полноценный «Ход конём».
3. **Глубже** (главы 21–25). Как React устроен внутри, серверный React (RSC, Next.js), настоящий проект на Vite, разбор чужого кода, финальный проект.

Каждая глава — 5–11 **шагов**. Шаг — одна идея и одно небольшое изменение кода с видимым результатом. В конце главы — **практикум** (решение по кнопке) и **«Под капотом»** (необязательно).

Врезки:
- **«Под капотом»** (`::: deep`) — внутреннее устройство;
- **«Вы встретите в старом коде»** (`::: legacy`) — классы, `forwardRef`, `useEffect` для данных, React Router 5/6, `connect()` и т. п. Читать умеем, писать — нет;
- **«Как в настоящем проекте»** — чем превью отличается от Vite/Next (StrictMode, сборка, SSR).

Обозначения: **API** — что впервые вводится в шаге; **Результат** — что ученик видит в превью.
