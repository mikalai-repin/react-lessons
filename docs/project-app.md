# Сквозной проект: «Ход конём» на React

Тот же интернет-магазин настольных игр, что в `../angular-learn` (см. `../angular-learn/docs/project-app.md` — экраны, модель `Game`, маршруты API, учётные записи, промокоды). Здесь — только то, что отличается для React.

## Почему тот же проект

- Учебный бэкенд (`public/backend/`), данные (`data/*.json`) и обложки (`public/assets/covers/`) уже готовы и проверены — копируем без изменений.
- Ученик, прошедший оба курса, видит один и тот же магазин на двух технологиях — это лучшее сравнение Angular и React (можно ссылаться во врезках `::: tip`).
- Магазин естественно требует почти всего стека: состояние, роутинг, серверные данные, формы, авторизацию, UI-кит (админка), тесты, производительность (большой каталог).

Если автор решит сменить проект — менять здесь и в `course-plan.md` до начала глав.

## Потребность → что изучаем

| Потребность магазина | Что изучаем |
|---|---|
| Карточка, список карточек | компоненты, JSX, props, `key` |
| Счётчик корзины, сумма, скидки | `useState`, неизменяемость, вычисление при рендере, `useReducer` |
| «В корзину» в карточке, корзина в шапке | подъём состояния → контекст → Zustand → Redux Toolkit |
| Таймер скидки, «Показать ещё», фокус | `useRef`, `useEffect`, свои хуки |
| Каталог → игра → корзина → заказ | React Router: маршруты, параметры, `loader`/`action`, ленивые маршруты |
| Каталог с сервера, поиск, фильтры, страницы | Suspense, TanStack Query, переходы, `useDeferredValue`, состояние в URL |
| Отзыв, «В избранное» мгновенно | Actions, `useOptimistic`, мутации Query |
| Вход, оформление заказа | React Hook Form + Zod, Actions |
| Кабинет и админка только для своих | авторизация, защита маршрутов |
| Админка: таблицы, формы, модальные окна | Ant Design 6, TanStack Table |
| 1000 игр, анимации | `memo`, React Compiler, виртуализация, `motion` |
| «Не сломать при правке» | Vitest + Testing Library |

## Файлы приложения (целевая структура к концу части 2)

Корень шага соответствует `src/` Vite-проекта. Компоненты — `PascalCase.tsx` + `PascalCase.module.css`, хуки — `useX.ts`, остальное — `camelCase.ts`. Решение принимается на этапе 1 и фиксируется в `lesson-format.md`; в главе 20 (архитектура) структура может быть переразложена по фичам.

```
main.tsx                       createRoot, StrictMode, провайдеры
App.tsx                        корневой макет (до главы 10), затем routes.tsx + Layout
styles.css                     глобальные стили магазина (готовый файл, как в angular-learn)
routes.tsx                     маршруты (глава 10)
layout/
  Header.tsx                   шапка: логотип, избранное, сводка корзины
  Layout.tsx                   макет с <Outlet> (глава 10)
  Breadcrumbs.tsx              крошки из handle маршрутов (глава 10)
shared/
  GameCard.tsx / .module.css   карточка игры
  Rating.tsx                   звёзды (глава 3, управляемый — глава 5/20)
  Quantity.tsx                 «− N +» (управляемый/неуправляемый — глава 20)
  Tabs.tsx                     составной компонент (главы 6, 20)
  format.ts                    formatPrice «1 290 ₽», formatPlayers, formatDuration (Intl)
hooks/
  useLocalStorage.ts, useDebouncedValue.ts, useInView.ts, useCountdown.ts, useMediaQuery.ts (глава 7)
store/
  cartStore.ts                 корзина: редьюсер (5) → контекст (8) → Zustand (9) → RTK (19)
  favoritesStore.ts
  authStore.ts                 (глава 14)
api/
  client.ts                    apiFetch: базовый адрес, токен, 401 (главы 11, 14)
  games.ts                     queryOptions для игр, категорий, отзывов (глава 11)
  orders.ts
  models.ts                    типы Game, CartItem, Order, User
  schemas.ts                   Zod-схемы (глава 13)
catalog/                       каталог, фильтры, поиск (фильтры — в URL, глава 10)
game/                          страница игры, отзывы (Suspense), «Похожие»
cart/                          страница корзины, промокод
checkout/                      оформление (RHF + Zod), блокировка ухода
auth/                          вход, защита маршрутов
account/                       кабинет: избранное, заказы
admin/                         админка на antd (ленивый раздел)
```

## Что приложение получает по главам

| Глава | Что добавляется в магазин |
|---|---|
| 1 | Корневой компонент «Ход конём», глобальные стили, StrictMode |
| 2 | Карточка одной игры из данных (`api/models.ts`, `data/games.ts` — локальный массив), список карточек |
| 3 | `GameCard`, `Rating`, стикеры через props-элементы, кнопка-обёртка |
| 4 | Счётчик и мини-корзина из позиций, корзина в шапке (подъём состояния) |
| 5 | Живой поиск, категория, «в наличии» и сортировка (вычисление при рендере; `catalog/CatalogFilters.tsx`, `catalog/filters.ts`), подписка в подвале (`layout/Footer.tsx`, неуправляемые поля), страница игры с отзывом (`game/GameDetails.tsx`, `selectedId`, сброс через `key`), корзина на редьюсере (`store/cartReducer.ts`, `useImmerReducer`) |
| 6 | Окно «Подробнее» (`<dialog>`), таймер скидки, фокус в поиске, «Показать ещё» (`IntersectionObserver`), подсказка в портале, «Нет сети» |
| 7 | Хуки `useLocalStorage`, `useDebouncedValue`, `useInView`, `useCountdown` |
| 8 | `CartProvider` (контекст + редьюсер), `FavoritesProvider`, тема |
| 9 | Корзина и избранное — Zustand с `persist`, склад и промокод |
| 10 | Маршруты: главная, каталог (фильтры в URL), игра `/games/:id`, корзина, кабинет (вложенные), оформление (защита), 404, ленивая админка, крошки |

| 12 | Плавный поиск (переходы), отзыв через Actions, оптимистичное избранное, `<Activity>` во вкладках |
| 13 | Вход, оформление заказа, отзыв — RHF + Zod |
| 14 | Авторизация: `authStore`, сессия, токен в `apiFetch`, 401, защита и `returnUrl`, роли, «Мои заказы» |
| 15 | Тема antd «Ход конём», уведомления, корзина в `Drawer`, таблица заказов, каталог на antd (практикум) |
| 16 | Мемоизация карточек, React Compiler, виртуализированный каталог, анимации корзины |
| 17 | Тесты корзины, карточки, каталога, оформления |
