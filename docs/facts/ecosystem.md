# Проверено: Библиотеки

Immer, Zustand, Jotai, React Router 8, TanStack Query, antd — что проверено запуском и по исходникам установленных версий. Правила — в `docs/modern-react.md`. Новый факт — строкой в таблицу, с источником (тип, исходник, лог, `checks/…`).

Документация: `devtools` — последним (снаружи), middleware — только на собранном сторе, не в срезах | `esm/middleware.mjs`, `checks/ch09-app-state.mjs` (9.5), docs/learn/guides/advanced-typescript.md, slices-pattern.md |
