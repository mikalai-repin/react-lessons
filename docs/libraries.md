# Библиотеки экосистемы React

Документ отвечает на вопрос «что, кроме React, нужно знать senior-разработчику» и фиксирует, **какие библиотеки входят в курс, в какой версии, зачем и насколько глубоко**.

Версии — последние на npm на **2026-10-06** (`npm view <пакет> version`). Это ориентир, а не фиксация: точные версии фиксируются в `package.json` при подготовке главы (как `@angular/*` в angular-learn — без `^`). Перед главой — сверить API по `node_modules/<пакет>` установленной версии: в памяти модели много старых мажорных версий этих библиотек.

Уровни глубины:
- **Глубоко** — отдельная глава или несколько шагов, «под капотом», типичные ошибки, практикум;
- **Рабочий** — 1–3 шага: уверенное использование в магазине;
- **Обзор** — врезка или шаг-обзор: что это, когда брать, чем отличается; без кода в магазине или с минимальным.

## Почему именно так (решения)

- **Роутер — React Router**, а не TanStack Router: он распространён в разы шире, его framework mode — путь к SSR без Next. TanStack Router — обзор.
- **Серверное состояние — TanStack Query** как основной инструмент; RTK Query — в главе Redux для сравнения.
- **Клиентское состояние — Zustand** как основной; Redux Toolkit — отдельная глава (как NgRx в angular-learn) из-за распространённости в существующих проектах; Jotai — обзор модели атомов.
- **Формы — React Hook Form + Zod.** Формы antd (`Form`) — в главе antd, с честным сравнением и связкой RHF + поля antd.
- **UI-кит — Ant Design 6.** До главы 15 — свои компоненты: ученик должен уметь строить компоненты сам, а затем понимать, что даёт кит.
- **Стили — CSS Modules** в коде курса (поддерживаются Vite «из коробки» и легко эмулируются в превью). Tailwind и CSS-in-JS — обзор.
- **Next.js — только в части 3** и только на машине ученика: RSC нельзя честно показать в превью без сервера.

## Что проверить для платформы (этап 0)

Для каждой библиотеки с пометкой «да» в превью — собирается ли она esbuild в ESM с внешними `react`/`react-dom`, и работает ли с **одним** экземпляром React (иначе — «Invalid hook call»). Особые случаи:

- `antd` — большой пакет, cssinjs вставляет `<style>` в `document.head` iframe — проверить; бандл целиком (без tree-shaking) — оценить размер; возможно, отдельный бандл, который грузится только в главах 15+.
- `react-router` — экспорт `react-router/dom` (`RouterProvider`) — сверить подпути.
- `msw` — Service Worker в iframe по blob/`srcdoc`-адресу; скорее всего, заменить на учебный бэкенд.
- `@babel/standalone` + `babel-plugin-react-compiler` — размер и время компиляции в воркере.
- Типы всех пакетов для Monaco (`.d.ts`) — как для `@angular/*` в angular-learn (заглушки подпутей из `exports`).
